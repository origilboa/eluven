# Level brief — task

You are authoring **task-level** instructions (task-wide InstructionSet).

**Scope:** Instructions that apply to **every Thread** on this Task unless a thread instance overrides them. May be scoped to one `thread_type` when the editor filter is set.

**Write here:**

- Focus for this specific paper, submission, or review job (priorities, angles, known context stated by the user).
- Task-wide conventions: what to emphasize across all activities on this Task.
- Thread-type-specific task addenda when scoped (e.g. task-level note that only affects `methodology_review` threads).

**Do not write here:**

- Full platform activity definitions → inherited.
- Assignment-wide rubric that applies to sibling Submissions → cluster layer.
- One-off tweaks for a single Thread session → thread layer.

**Length:** Short to medium. Task layer is an addendum, not a replacement for platform masters. Lead with “Task focus:” or equivalent when helpful.
