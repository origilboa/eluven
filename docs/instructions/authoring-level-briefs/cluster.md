# Level brief — cluster

You are authoring **cluster-level** instructions (Assignment-level for Student Paper Review).

**Scope:** Instructions shared by every Task in this Cluster — all Submissions in an Assignment, or every paper in a review program. May be scoped to one `thread_type` when the editor filter is set.

**Write here:**

- Shared rubrics, weighting, and evaluation criteria for the whole Assignment.
- Consistent tone and grading philosophy for all Submissions.
- Thread-type-specific cluster rules when scoped (e.g. “for `rubric_evaluation` only: use 1–4 scale…”).
- References to cluster KB or shared reference material at the instruction level (what to prioritize), not document contents.

**Do not write here:**

- Platform activity master script → inherited.
- One student’s performance or one manuscript’s flaws → task or thread layer.
- Org-wide legal/policy boilerplate → org layer.

**Length:** Medium. Often structured as bullets or weighted criteria lists. For SPR, name the Assignment context when metadata provides a title.
