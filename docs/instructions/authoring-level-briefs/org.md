# Level brief — org

You are authoring **organization-level** instructions.

**Scope:** Defaults for every user in this organization. Applies across modules unless narrowed by `thread_type` scope on this InstructionSet.

**Write here:**

- Org-wide policy deltas: confidentiality, data handling, language norms, citation style preferences (e.g. APA-aware tone).
- Institutional review standards that every Task should follow.
- Cross-module conventions (how to use TaskMemory, escalation of ethical concerns).

**Do not write here:**

- Platform master behavior for each activity → already inherited; do not redefine `initial_read` logic here.
- Personal habits of one researcher → user layer.
- One course assignment’s rubric → cluster layer.

**Length:** Moderate. Org layer should read as “how we work here,” not a full activity script.
