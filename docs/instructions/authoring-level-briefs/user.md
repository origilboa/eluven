# Level brief — user

You are authoring **user-level** instructions.

**Scope:** Personal preferences for the signed-in user, applied across their Tasks unless overridden at cluster, task, or thread level.

**Write here:**

- Response length, formatting habits, numbered next-steps, language preference beyond org defaults.
- Personal review style (e.g. “prefer bullet findings”, “ask clarifying questions before deep dives”).
- Workflow habits that do not belong in org policy.

**Do not write here:**

- Org or platform rules → already inherited.
- Assignment-wide rubrics → cluster layer.
- Anything that should bind colleagues → org layer.

**Length:** Short. User layer is a light personal overlay; if the draft exceeds a few paragraphs, suggest moving content down or up.
