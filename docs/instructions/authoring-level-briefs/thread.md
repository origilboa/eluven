# Level brief — thread

You are authoring **thread-level** instructions (per-Thread instance InstructionSet).

**Scope:** Instructions for **this Thread only**. Seeded from ActivityLibrary default when the Thread was created; the user edits the instance here.

**Write here:**

- Smallest delta: opening format, one extra constraint, a specific question list, instance-only emphasis.
- Adjustments that should not affect other Threads on the same Task.

**Do not write here:**

- Task-wide focus that applies to all threads → task layer.
- Master activity behavior → platform / ActivityLibrary default (already inherited or seeded).
- Long rubrics or role definitions → move up to cluster, task, or platform.

**Length:** Short — often one paragraph or a tight bullet list. If the draft rivals platform length, recommend relocating content to a higher layer.
